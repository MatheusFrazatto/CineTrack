# CineTrack

O CineTrack é um sistema web desenvolvido como projeto integrador da disciplina de Programação de Sistemas Web na Universidade Estadual de Maringá (UEM). A aplicação funciona como um gerenciador pessoal de filmes, permitindo ao usuário cadastrar, listar, buscar e filtrar seus títulos favoritos. No primeiro módulo, o foco do projeto é a construção de um frontend interativo e dinâmico. Na etapa seguinte, a aplicação evoluirá para um modelo full stack com a integração de uma API REST e persistência de dados.
